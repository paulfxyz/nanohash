# nanohash v0.2.0: a separate lite generator

This additive release introduces `@paulfxyz/nanohash/lite` while preserving the existing full-toolkit API. The lite import generates one lowercase Base36 public identifier per call and does not include the toolkit's other helpers.

## Measured footprint

For the lite-only browser ESM bundle, the reference build measures **949 bytes minified**, **579 bytes minified + gzip**, and **509 bytes minified + Brotli**. These figures include bundled Nano ID code and lite's runtime checks; the [size methodology](https://github.com/paulfxyz/nanohash/blob/main/docs/bundle-size.md) documents all settings and exclusions.

The full generator factory remains 1,369 bytes minified + gzip, and the root browser API remains 2,707 bytes under the same settings. A separate CI check enforces a 750-byte minified-plus-gzip ceiling for lite.

## Use it

Install the tagged GitHub release; the scoped package has not been published to npm. Do not install the unrelated unscoped npm package named `nanohash`.

```sh
npm install github:paulfxyz/nanohash#v0.2.0
```

```js
import { nanohash } from "@paulfxyz/nanohash/lite";

nanohash();                      // 8 characters
nanohash(12);                    // 12 characters
nanohash(5, { allowTiny: true }); // explicit tiny public-code acknowledgement
```

ESM, CommonJS, and TypeScript declarations are included. See the [lite reference](https://github.com/paulfxyz/nanohash/blob/main/docs/lite.md) for the exact contract and the distinction from the root `nanohash(length)` shorthand.

## Scope and verification

- **Kept in lite:** Secure Nano ID randomness, length validation, strict options, explicit tiny-code gating, and fail-closed Web Crypto handling.
- **Left out of lite:** Presets, custom alphabets, factories, batching, analysis, allocation, and format-validation exports.
- **Tests:** 99 unit/CLI checks and 20 desktop/mobile Chromium checks, plus ESM/CJS declarations and clean tarball consumer installation.
- **Compatibility:** The existing runtime sources, root declarations, and full-toolkit JavaScript builds are unchanged.
- **Versioning:** v0.1.0 remains immutable; updated documentation and installation examples point to v0.2.0.

These are public identifiers, not access secrets or cryptographic hashes, and no independent security audit is claimed. Source archives include committed builds, while npm publication remains a separate decision.
